# SM&A — Frontend

Base da aplicação de apontamento de horas por projeto, construída com React, TypeScript, Vite, Tailwind CSS e React Router.

## Execução local

```bash
npm install
npm run dev
```

O Vite exibirá no terminal o endereço local da aplicação.

## Validação

```bash
npm run typecheck
npm run lint
npm test
npm run build
```
